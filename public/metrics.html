Countries

Each browser counts as one visitor per day, using a hash that changes daily and is never linked across days, so someone who comes back tomorrow counts again. Country is looked up from the IP address when the visit arrives; the address itself is never stored. Days are in UTC. Visitors with Do Not Track or Global Privacy Control turned on aren’t counted. Country lookup uses IP Geolocation by DB-IP.
